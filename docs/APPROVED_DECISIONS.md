# BUNKER 42 — утверждённые решения

Статус: все шесть решений явно утверждены пользователем ответом «да» в чате координатора. Дополнение разрешает неоднозначности GAME_RULES.md v1.0; исходный файл сохраняется как источник.

1. Несколько спецкарт одного окна разрешаются по исходному порядку игроков r.order, а не по сетевой скорости или вращающемуся порядку текущего раунда.
2. SPECIAL_BEFORE_REVEAL и SPECIAL_FINALE длятся по 15 секунд.
3. reveal_extra_self после основного раскрытия владельца открывает выбранную допустимую закрытую карту немедленно, при принятии действия; ждать end_turn/тайм-аут выступления нельзя. Основной 30-секундный дедлайн не продлевается, карта остаётся одноразовой, вне окна/чужого хода недоступна.
4. Если профессия уже открыта force_reveal_target до первого хода, сохраняется 30-секундный слот выступления без обязательного второго раскрытия.
5. Ранее поданный голос против игрока, добровольно покинувшего партию, не является действительным на дедлайне голосования. Пока VOTING открыт, голосующий может выбрать другую допустимую цель. Если к закрытию бюллетеней активный голосующий не имеет действительного голоса, применяется штрафной автоголос против самого голосующего, включая защищённого. При уходе самого голосующего его уже поданный действительный голос против остающейся активной цели сохраняется. После закрытия голосования поздние действия не переписывают закрытые бюллетени.
6. При входе в финал состав победителей фиксируется. Уход/закрытие страницы после этого не меняет статусы финалистов, состав победителей, результат или дедлайн SPECIAL_FINALE. Интерфейс предлагает выйти на главную/закрыть экран без команды игрового withdrawal; попытки изменить состав через API должны отклоняться.

## Ограничения второго цикла
Не менять стек, контракт API, исходный GAME_RULES.md, владение файлами или исходный /data/bunker42. Исправления — в отдельных копиях агента. Объединение только координатором. Согласование не означает разрешение на новые сервисы, расходы или публичное развёртывание.
