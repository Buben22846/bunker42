# Проверка выдаваемой сборки

Версия: BUNKER 42 MVP 0.1.0. Дата: 2026-10-12.

## Автоматические проверки

На объединённых backend + frontend выполнен `npm test`:

- **182 теста: 182 PASS, 0 FAIL, 0 SKIP, 0 TODO.**
- До включения дополнительных backend-регрессий независимый набор базовых + QA тестов дал 129/129 PASS.
- Проверяются составы 4–16, независимая таблица квот, приватность, устаревшие/повторные запросы, все эффекты, ресурсные ограничения, уход игроков, шесть утверждённых решений, журнал, валидаторы, конкурентный HTTP и сохранение/рестарт.
- При упаковке изменены только расположения/временные пути тестовых harness, не ожидаемые результаты утверждённых проверок.

## Браузерная проверка общей сборки

Chromium, настоящий HTTP-сервер и общий код приложения. Подмена ответов room API не использовалась.

1. Четыре независимых браузерных контекста: создание, вход, готовность, старт, продолжение, реальное 15-секундное окно, раскрытие, обновление страницы и завершение выступления. Имя с HTML-символами остаётся текстом.
2. Дополнительное раскрытие на сервере становится публичным немедленно, до end_turn; таймер сохраняется.
3. Уход цели вызывает предупреждение и снятие выделения; новое ручное голосование принимается сервером. Окно правил закрывается Escape.
4. На финальном экране переход на главную и возврат не отправляют withdrawal; попытка direct leave отвергается; состав и дедлайн сохраняются; сервер завершает финал по таймеру.
5. Offline/reconnect: кнопки недоступны без связи и возвращаются после актуального снимка.

Для поздних этапов комнатам задавались отдельные стартовые сохранения, сформированные тем же движком, — это позволяет проверить реальные серверные переходы без ожидания полной длительности партии. Полная человеческая 25–50-минутная игра не проводилась. Ошибок JavaScript pageerror в этих проверках нет.

В первом прогоне браузерного harness исправлено ожидание синхронизации всех клиентов (polling до 1 секунды); после исправления harness повторный полный прогон прошёл. Изменение продукта ради обхода теста не выполнялось.

## Визуальная проверка

Осмотрены 11 итоговых PNG по одному: главная и лобби на 390px/1440px, раскрытие на desktop, дополнительное раскрытие на телефоне, предупреждение голоса на телефоне, голосование на desktop, окно финала на телефоне, результаты на телефоне/desktop. Перекрытий и горизонтального переполнения в этих снимках не обнаружено. Дополнительные состояния формы, фокус/ошибки, сценарий на телефоне и диалог проверены frontend-агентом; это не заменяет тесты всех реальных устройств.

## Границы гарантии

Это проверенный MVP для компании друзей, не заявление о production-готовности.

Не проводились: Safari/Firefox, физические телефоны, 16 одновременных браузеров, длительная нагрузка, полная человеческая партия, аварии файловой системы, эксплуатация публичного сервиса, внешний HTTPS/proxy и Docker-развёртывание. Синхронный JSON-save не обещает fsync/crash-durability или rollback при ошибке записи. Событие player_reconnected при polling пока не моделируется. Нет регистрации/переноса доступа на другое устройство и встроенной голосовой связи.

Архив не содержит игровые сохранения, bearer-токены, локальные зависимости, runtime fixtures и журналы с приватными данными.
