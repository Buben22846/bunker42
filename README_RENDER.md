# Публикация BUNKER 42 на Render Free

В этой папке только файлы для запуска сайта. Сохранений и секретов игроков нет.

GitHub: создайте репозиторий, загрузите СОДЕРЖИМОЕ папки bunker42, сохраняя папку public. package.json и server.mjs должны находиться в корне репозитория.

Render: New -> Web Service -> подключите репозиторий.
Language: Node
Build Command: npm install
Start Command: npm start
Instance Type: Free
Root Directory: оставить пустым, если package.json в корне.
Не добавляйте платный диск или платный тариф.

После успешного запуска откройте адрес onrender.com, создайте комнату и скопируйте приглашение друзьям. Им не нужно ничего устанавливать.

После игры всем нужно закрыть страницы с комнатой. Бесплатный Render засыпает после 15 минут без обращений. Открытая комната отправляет запросы и может поддерживать сервер активным.

При сне, рестарте и новом развёртывании сохранения теряются. Каждый раз создавайте новую комнату. Это не вариант для долговременного хранения партий. Запуск после сна может занять около минуты; у бесплатного тарифа есть лимиты.

Если Render требует оплату или сообщает ошибку при запуске — не выбирайте платный тариф, сначала покажите сообщение координатору.
